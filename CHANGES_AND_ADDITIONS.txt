    expiry tracking, attempt rate limiting, and verification state.

• backend/app/routes/auth.py & backend/app/schemas/auth.py:
  - Implemented 3-step Google Authentication pipeline:
    1. /auth/google: Validates Google token. Determines whether the user is an
       existing resident or a new user. If profile is incomplete, responds with
       needs_profile_completion: true and temporary session token.
    2. /auth/complete-profile: Collects mandatory resident information (Full Name,
       Contact Number, Subdivision, Street Address) and triggers 6-digit OTP.
    3. /auth/verify-otp: Verifies OTP code before issuing final JWT tokens.
