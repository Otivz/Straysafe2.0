# Engineering Quality Reference

This index routes reviewers to focused, evidence-based practice reviews. Engineering findings are advisory unless they reveal a separate correctness, reliability, or security defect.

Use `Applied`, `Partial`, `Recommended`, `Unverified`, or `N/A`. For each recommendation, record observable evidence, impact, an owner, and a verification step.
